# Fireside Mobile SDK

Run a Fireside Interview inside your own mobile app.

This repository holds the **licence** and the **install docs**. The SDK itself
is published to each platform's standard package registry.

## Install

| Platform | Where it comes from | Coordinate |
|---|---|---|
| Android | Maven Central | `ai.fireside:sdk-android` |
| iOS | Swift Package Manager | `github.com/fireside-hq/fireside-ios-sdk` |
| Flutter | pub.dev | `fireside_flutter` |

Every release carries the same version number on all three platforms.
